# Орбита

Платформа для репетиторов разных предметов: расписание, ученики, материалы, переписка и совместная доска. Статические HTML/CSS/JavaScript, Firebase Authentication и Realtime Database. Сборка не требуется.

Сайт: https://toot54.github.io/English-Space/

## Локальный запуск

```sh
node scripts/preview.cjs
```

Открыть http://127.0.0.1:4173. `?demo=1` включает кабинет с примерными данными без подключения к базе и без сохранения. Реальный вход требует домен, разрешённый в Firebase Authentication.

## Интерфейс и доступ

- Зелёное оформление «Орбита», публичная главная страница, демо, светлая и тёмная темы.
- Мобильная навигация, адаптивные формы, календарь, админка и панель инструментов доски.
- Административный аккаунт открывает только административный кабинет. Проверяется Firebase UID и подтверждённый email; роль из профиля не выдаёт прав администратора.
- Подтверждение почты перед доступом к кабинету; проверка также выполняется правилами базы.
- История занятий, индивидуальная цена, ручные отметки оплаты и экспорт CSV.
- Личная тетрадь со стабильным вводом, удалением блоков и страниц; общий конспект урока на доске.
- Фон доски «Точки / Клетка / Без разметки», график квадратичной функции, лента времени, решение задачи и сравнение.
- Правила Firebase закрывают чужие профили, доски, чаты, обращения и заявки. Доступ ученика к доске хранится в `boardAccess`. Назначенные доски получают доступ при загрузке кабинета учителя; отправка в чат и приглашение в класс также выдают доступ.
- Изменение тарифа и срока доступно только администратору. Ручное подтверждение оплаты продлевает подписку на 30 дней; истёкший тариф отображается как бесплатный.
- Исправлены обработка нескольких касаний, отмена рисования, загрузка сохранённой доски перед событиями, повторная обработка событий и экранирование пользовательского текста.
- Видеозвонок использует WebRTC, ограничение видеобитрейта и ограниченные повторные попытки подключения. Автоматическая передача аудио/видеокадров через Firebase отключена.

## Проверки

```sh
node scripts/check.cjs
node scripts/smoke.cjs
node scripts/security.test.cjs
node scripts/board.test.cjs
node scripts/ledger.test.cjs
```

Проверяются синтаксис, ресурсы, ID элементов, демо-разделы, отдельный кабинет администратора, выражения правил, экранирование данных доски и повторные подключения.

`node scripts/emulator.test.cjs` требует официальный Firebase Database Emulator на `127.0.0.1:9000`. Использует только синтетические данные в пространстве `orbita-test`. Проверяет компиляцию правил, приглашения, доступ к доскам, запрет посторонним, защиту баланса и тарифа, поддержку и оплату. Проверка пройдена перед публикацией.

## Публикация

GitHub Pages публикует ветку `main`. Для сайта нужны `index.html`, `board.html` и `assets/`; файл проверки Google сохранён. Локальные резервные копии, инструменты, авторизация и данные пользователей исключены из Git.

Правила базы публикуются отдельно, вход владельца через Firebase CLI:

```sh
node scripts/build-rules.cjs
firebase deploy --only database --project english-space-13381
```

Авторитетный исходник правил — `scripts/build-rules.cjs`; результат — `firebase/database.rules.json`. Обновлять и проверять оба файла совместно.

## Что остаётся до платного запуска

- Пройти реальный урок с двумя аккаунтами и разными сетями, включая Chrome Android и Safari iPad/iPhone. Проверки в браузере на размерах телефона и планшета не заменяют проверку клавиатуры и звонка на реальных устройствах.
- Подключить TURN с временными серверными учётными данными: сейчас настроен только STUN, поэтому некоторые сети не позволят установить звонок. Постоянный секрет TURN нельзя помещать в публичный JavaScript.
- Реализовать серверный контроль количественных ограничений тарифов. Сейчас сроки и назначение тарифа защищены, но заявленные ограничения числа учеников и досок ещё не обеспечены сервером. До этого принимать оплату за эти ограничения нельзя; при пустых реквизитах оплата недоступна.
- Проверить платёжные реквизиты и процесс ручной сверки, определить условия сервиса и обработки данных. Автоматического эквайринга, чеков и регулярного списания нет.
- Текущее сохранение доски использует общий снимок; необходимо дополнительно проверить конкурентные изменения и восстановление после длительной работы без сети. Сервис пока следует запускать как пилот с небольшой группой.
